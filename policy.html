GeoFlood (« nous », « notre », « nos ») s'engage à protéger la confidentialité des utilisateurs de l'application mobile et de la plateforme web GeoFlood.

En utilisant GeoFlood, vous acceptez les pratiques décrites dans cette politique de confidentialité.
01

Données collectées

GeoFlood peut collecter les informations suivantes selon votre usage de l'application :

Données de compte
  • Nom complet
  • Email professionnel
  • Numéro de téléphone
  • Organisation
Données de localisation
  • Coordonnées GPS
  • Altitude
  • Précision de localisation
  • Historique terrain
Données opérationnelles
  • Zones inondées signalées
  • Photos terrain
  • Notes & observations
  • Rapports générés
Données techniques
  • Modèle d'appareil
  • Version système
  • Adresse IP
  • Journaux d'erreurs

Les applications utilisant la localisation divulguent clairement comment les données GPS sont collectées et utilisées, conformément aux exigences des stores d'applications.

02

Utilisation des données

Nous utilisons les données collectées exclusivement pour les finalités suivantes :

  • Fournir des alertes inondation en temps réel
  • Afficher les cartes de risques hydrologiques
  • Synchroniser les rapports terrain en temps réel
  • Améliorer la précision des modèles prédictifs
  • Détecter et corriger les erreurs techniques
03

Partage des données

Nous ne vendons aucune donnée personnelle. Le partage est limité aux entités strictement nécessaires aux opérations :

🏛️ Organismes publics partenaires 🏙️ Collectivités territoriales 🚨 Équipes d'intervention autorisées ☁️ Prestataires cloud sécurisés
04

Conservation des données

Les données sont conservées uniquement pendant la durée nécessaire aux opérations, aux obligations contractuelles ou aux exigences réglementaires applicables. À l'issue de cette période, les données sont supprimées ou anonymisées de manière sécurisée.

05

Sécurité

GeoFlood met en œuvre des mesures de sécurité robustes pour protéger vos données :

  • Chiffrement de bout en bout des communications
  • Authentification sécurisée multi-facteurs
  • Contrôle d'accès granulaire par rôles (RBAC)
  • Sauvegardes chiffrées et redondantes
06

Vos droits

Conformément à la réglementation applicable, vous disposez des droits suivants :

📋 Accès Demander l'accès à vos données personnelles
✏️ Rectification Corriger des informations inexactes
🗑️ Suppression Demander l'effacement de vos données
↩️ Retrait Retirer votre consentement à tout moment

Pour exercer ces droits, contactez-nous à privacy@geoflood.africa.

07

Permissions de l'application

GeoFlood peut demander les permissions suivantes sur votre appareil. Elles sont utilisées uniquement pour les fonctionnalités métier :

📍 Localisation GPS
📷 Appareil photo
💾 Stockage local
🔔 Notifications push
